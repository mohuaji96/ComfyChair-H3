# 剧情组合为什么写不连贯（通俗说明与改法）

看的是生成剧情那部分程序、成人档的词库、还有剧情组合这个界面。

## 一、先说结论

这套随机组合，产出的是「一句话」，不是「一场戏」。

它把地点、人物、穿着、动作全揉进一段话，一气说完。这段话里没有「第几秒」、没有「第几个镜头」，
也没有「这一段结束时人在哪、插在哪、穿着什么」。下游要拿它去写视频提示词，就得自己切分、自己补走位，
补错的地方全都集中在三处：人物凭空到位、动作挤成一团、换地方时不写先抽出来。

## 二、它现在是怎么拼出来的

一共五步，顺序就是句子的顺序：

1. 先定世界观和人数，决定后面哪些词能用
2. 抽人物：种族、肤色、身材、发型、胸部、配饰、眼镜，拼成一句长相介绍
3. 抽场地、时间、光线、穿着、袜子、鞋子
4. 抽一句日常动作当开场，再抽一句「开始」当起手式（固定是「他忽然上前……」）
5. 抽动作链：固定两到三组，每组一个姿势配一个动作，组与组之间插一句过渡，最后接一句结束

毛病主要出在第 5 步。过渡句只有三句，而且都是「换个姿势」这个级别，没有「走过去」「按下去跪」这种让人移动的句子。

## 三、三个方面的毛病

### 故事接不上

- 从「站着量三围」到「跪着被插」，中间没有人动过一步，下游只能自己补，补出来就是「她突然就跪好了」
- 第二位女性全片只有穿着，没有「她此刻在干什么」的位置，所以她只能靠在某处，然后凭空出现在别人嘴边
- 每一组结束时，谁在哪、插在哪、穿什么，系统不记账。下一组开场只能靠猜，经常和前一组收尾对不上
- 场地会跳：同一批设定连抽两次，可能一次在餐桌、一次在浴室，前一场留下的东西没有承接的地方

### 节奏不受控

- 一句话里塞五到八个动作，十四秒装不下；换成三十六秒，又还是两三个动作，前面挤、后面空
- 原因是抽几组写死成两到三组，跟你要多少秒没有关系
- 没有「镜头」这个概念：不分镜、不定机位（摄影机摆在哪）、没有景别。下游每一镜自己编，容易一个景别到底
- 细节永远堆在句尾，因为拼句子的顺序把细节、痕迹、情绪排在所有动作之后，塞不进每一拍里

### 动作做不出来

- 换地方不写先抽出来。肛门那一步是单独一格，直接接在动作链末尾，不管此刻人在哪，于是出现「一根同时占两处」
- 收尾不看姿势。射在胸口、射在脸上这些收尾，不检查她当时是趴着还是仰着。趴着胸朝下，射在胸口就是错的
- 姿势之间不保证接得上。从「站着抱起一条腿」直接跳到「骑上去」，现实里得先把腿放下来
- 「一根只能在一处」这条根本不成立。系统只用一个开关决定连接词是「顺势挺腰」还是逗号，没有「此刻插在哪」的记忆

## 四、怎么改（三层，按顺序做）

### 第一层：给词条补关系，不补新词

现在每条词只知道自己「能不能出现在这句话里」。要让它还能回答「排在第几拍」「接不接得上上一拍」，补六样：

1. 进场走位：怎么进到这个姿势。比如「他握住她的腰把她转过去，按在桌沿」
2. 离场走位：怎么离开这个姿势
3. 建议秒数：这一拍大概几秒
4. 通道：这一拍占用哪个部位，从阴道、肛门、嘴、手里选一个，或者写「没有」
5. 抽出句：换通道时那句「先抽出来」。通道变了而这一格空着，这条就不许用
6. 参与者：谁做，女方、男方、女方二

收尾那一组另加两样：要求的姿态（趴、仰、站、跪），要求的通道（已经拔出、还在体内）。

先补二十条就够用：肛门八条、收尾十二条。这二十条是现在所有「做不出来」的源头，补完立刻见效。

### 第二层：先排拍表，再写句子

把现在「一边抽一边拼」改成两步：先排出一张拍表，再把拍表写成话。
拍表每一行是一拍，写明谁、什么姿势、做什么、几秒、从哪换到哪。

配五条规矩：

1. 按秒数分配。给定多少秒，就按每拍的建议秒数往下累加，到满了就停，收尾那一拍永远保留，超了就丢它前面那拍
2. 按动作数卡。一拍只做一件事，所以动作数等于拍数。十四秒最多六拍
3. 记住插在哪。整段只允许一个位置，位置变了必须先写「抽出来」，写不出来就不许换
4. 每一拍都要有人。一男两女时，第二位女性要么自己占一拍，要么在上一拍里被明确写进去（贴着脸、按着肩），不许只出现在人物介绍里
5. 每组留一份交班条。姿态、接触点、光、机位、穿着、情绪，六样写清楚。下一组照这条开场

镜头怎么合并：一个镜头放一到两拍，每个镜头两到四秒；十四秒最多三个镜头；相邻两个镜头不能同一个景别。

### 第三层：界面给表，不给散文

抽完先给一张表，不要直接给一段话。每一拍可以锁住，也可以单独换一条。
顶上一行显示「已用十二点五秒，共十四秒；动作五个，上限六个；镜头三个，上限三个」，超了标红。

「换一条」只换当前这一拍，不要整段重抽。整段重抽会把已经调好的几拍一起冲掉。

## 五、交付给下游的样子（六段）

一、规格：几组、每组几秒、总共几秒、用什么模式、竖屏还是横屏
二、人物卡：每个角色一行，长相、此刻穿什么、此刻在做什么
三、组表：第几组、几秒、这一组只干哪一件事、分几个镜头、每拍几秒
四、分拍表：这一组的每一拍，一行一拍
五、交班条：这一组结束时，姿态、接触点、光、机位、穿着、情绪
六、正文：照着拍表直译，不再自己加动作

示例（餐桌那段，两组十四秒）：

第一组

- 零到四秒：她赤脚站在餐桌旁，软尺绕在胸前量三围；另一位靠在椅背上看；他把腰上的浴巾扯下来扔到地上
- 四到九秒：他走过去，一只手把她的卷发从后颈拨到一边，低头吻下去；顺手把那块布料推到胸口上方
- 九到十四秒：他把她转过去，按在桌沿跪下、腰塌下来，握着腰挺进去；另一位从椅子上起身走过来，跪到她脸边，含住她的舌头

交班条（第一组结束）：她跪趴在桌沿、腰塌着；他双手握腰，插在里面；另一位嘴对着嘴，一只手搭在她肩上；光从左侧窗子进来，冷白；机位在侧后方，中近景；她上半身只剩一块布料堆在胸口，赤脚；另一位只剩丝袜和高跟鞋；他皮甲下面什么都没穿。

这样排的好处很直接：切口都在明处，谁也偷不了懒，谁也挤不进去。

## 六、三步走

第一步，止血，改动最小。只补肛门八条和收尾十二条的关系，再让系统记住「此刻插在哪」。
做完连抽五十次，不该再出现「换了地方不写先抽出」和「趴着射胸口」。

第二步，改流程。先排拍表再写句子，按秒数和动作数卡住。

第三步，改界面。换成拍表加预算条，支持单拍重抽。

这套东西本身不复杂。难的是它现在把结构交给了下游去猜。把结构挪回自己手里，下游就只剩翻译。

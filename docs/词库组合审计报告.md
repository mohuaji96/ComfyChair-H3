# 词库组合审计报告（增强模式 · 成人档）

审计对象：词库文件（成人档）＋ 组合引擎的成句顺序表。
审计范围：词条归位是否合理、成句顺序是否通顺、跨分类是否有互斥、兜底是否可控。
不在范围：画面质量、模型参数、生成工作流。

## 阅读说明

- 词条级结论均标注所属分类与所在格，可逐条回溯。
- 上衣款式格、性行为格这两个池在导出时被截断，凡涉及这两池的结论标「抽样可见」。
- 「应该挪到哪」是我的建议，不是唯一答案，可按你的习惯改。

分四批做，前两批不改任何校验逻辑，只动数据和顺序表。

# 第一部分 成句顺序审计

## 现状

```text
一、风格 → 影调色调
二、取景（镜头、裁切）→ 场景 → 人数
三、她是……（种族、妆容、年龄、气质、头发、眼睛、身材、乳房、腿、阴部、体液、皮肤）
四、穿……，戴着……，拿着……（上衣、下衣、穿脱、衣物细节、胸罩、内裤、袜子、鞋、头饰、饰品、道具）
五、姿态 → 头部姿态 → 男方句 → 性行为 → 动作 → 手部动作 → 表情 → 视线
六、第二位女性在做什么
七、支撑面
八、兜底
```

## 问题一：日常动作排在性行为之后（必改）

「动作」这一格里大部分是开场日常：擦镜子、喝水、系鞋带、扎头发、翻冰箱、煮咖啡。

顺序上它排在性行为后面，于是变成「后入，擦镜子」——先做完，再回去擦镜子。语序把因果颠倒了。

**改法**：这一格拆成两张表。开场的进「此刻正在做」，排在人物之后、姿态之前；过程的（缓慢前后移动、身体起伏、挺起上身迎合）留在性行为之后。

## 问题二：穿脱状态夹在衣物列举中间（必改）

第四段的顺序是外衣、穿脱、内衣。中间插一句「衣襟大敞，双乳外露」，列举被打断，读成「穿着这些、又脱了、又穿着这些」。

**改法**：状态句挪到衣物列举末尾，或单独成一小句。

## 问题三：内衣排在外衣之后（建议改）

现在是上衣、下衣、胸罩、内裤。写提示词的习惯是先贴身再外穿。

**改法**：衣物组内部按贴身、外穿、配件、道具排。

## 问题四：环境痕迹被排到最后（必改）

四十个分类里，三十九个都在顺序表中有位置，只有「环境痕迹」一格不在。它走兜底，追加在最后一段。

后果：「床单皱成一团」「地上的衣服」「镜子上蒙了一层雾」这二十条永远出现在末尾，排在表情和视线之后。整段收尾落在环境描写上，注意力被拉走。

**改法**：挪到场景之后。「场景是浴室」和「浴室里还弥漫着水汽」本来就该挨着。

## 问题五：兜底无条件追加（建议改）

以后词库新增分类，若忘记录进顺序表，会被静默排到最后，没人会发现。

**改法**：兜底时按分类的层级号插进对应位置，而不是一律追加末尾。

## 目标顺序

```text
一、风格 + 影调
二、取景 + 场景 + 环境痕迹 + 人数
三、她是谁：种族、年龄、气质、头发、眼睛、皮肤、身材、乳房、腿、阴部、体液
四、此刻在做什么：开场日常一句
五、穿着：胸罩、内裤、上衣、下衣、袜子、鞋、头饰、饰品、道具，末句穿脱状态
六、姿态 + 头部姿态 + 男方 + 性行为 + 手部 + 表情与视线
七、第二位女性在做什么
八、支撑面
```

这样第四段到第六段之间就是「她正在擦镜子、被按住」的转折，读起来有前后关系。

# 第二部分 词条归位（甲批）

## 一、内裤 · 颜色格混入姿态词

该格应只放颜色。以下五条不属于颜色：

| 词条 | 建议去向 |
| --- | --- |
| 走光意外 | 删除，或进「穿脱」 |
| 巧妙遮挡 | 删除，语义空 |
| 瞬间的走光 | 删除 |
| 双腿分开 | 进「姿态」 |
| 内裤从腰际微微露出 | 进「衣物细节」 |

抽中的后果：「黑色，双腿分开，丁字裤」。

## 二、胸罩 · 款式格混入状态

| 词条 | 问题 | 建议 |
| --- | --- | --- |
| 无胸罩 | 状态，与「穿脱」重复 | 删除，靠「穿脱」表达 |
| 没穿胸罩 | 同上 | 删除 |

款式格里现在既有「蕾丝胸罩」，又有「没穿胸罩」，抽到后者的同时前者的可能性没被排除，会出「没穿胸罩的半罩杯」。

## 三、头发 · 款式格混入动作

| 词条 | 问题 | 建议 |
| --- | --- | --- |
| 被抓住的头发 | 动作 | 进「手部动作」或「姿态」 |
| 一只手抓着头发 | 动作 | 同上 |
| 拨到一侧 | 动作，且状态格里已有近似 | 三处只留一处 |

## 四、动作格混入性行为（抽样可见）

明确属于性行为的三条：缓慢前后移动、身体起伏、挺起上身迎合。

另有五条边界模糊：慢慢压下身、身体贴上去、脸贴着脸喘气、凑近又退开、俯身向前。

建议：前三条移入性行为格；后五条按「开场能否单独成立」判断，能成立留动作格，不能成立移入性行为格。

## 五、胸围用了两套单位

同一格内并列：

- 文学词：贫乳、微乳、小巧胸部、中等胸部、丰满胸部、巨乳、爆乳、超巨乳
- 罩杯：A 至 G 罩杯

两套单位混抽，会出现「巨乳」与「E 罩杯」同框，或与身材格的「丰满」重复表达。

建议：只留一套。若两套都要，就锁死换算关系，抽到一套时另一套不再单独出。

## 六、镜头格混入光线与画质

| 词条 | 问题 |
| --- | --- |
| 逆光、逆光边缘光 | 光线，光影色调格里已有 |
| 浅景深、广角、长焦、微距、远摄 | 镜头参数，不是取景景别 |

同格还有构图指令：对角线构图、居中构图、三分构图、留白很多、极简背景。它们要和「特写」「过肩」并列抽取，会出「特写，三分构图，极简背景」这种一串互不相干的东西。

建议：这一格拆成三格——景别、机位角度、构图；光线词全部交出。

## 七、两处明显错格

| 词条 | 现所在 | 应为 |
| --- | --- | --- |
| 听诊器 | 饰品 | 道具，或随职业套装一起出 |
| 蜡油痕 | 皮肤·痕迹 | 需要「低温蜡烛」在场，加前置条件 |

## 八、需要场地条件的词（抽样可见）

姿势格里有一批与场地强绑定：被按在天台护栏、被按在书架前、被按在洗手台前、被按在落地窗前面对夜景、被抵在天窗下面雨敲玻璃、手撑镜面、坐在洗手台上晃腿。

道具格里也有一批需要固定点：悬吊吊环、拘束椅、吸盘固定器。

建议：这些词各自声明「需要什么场地或支撑面」，没有就不出。现在的场地支撑判断只覆盖姿势对床和墙的需求，没覆盖到「镜面」「护栏」「吊环」这类具体物件。

## 九、三人姿势混在单人姿势格里

三人并肩站着、三人围坐、三人并排跪坐、三人挤在沙发上、三人躺在床上、三人围成一圈跪着、三人手叠着手、三人背靠背、三人叠着躺在一起、三个人靠在一面墙上、两女一男叠在一起、一人被两人抬起。

建议：这些词带上人数要求，与人数格联动，人数不够时不出。若已有此判断，则只是数据没标，需要补标。

# 第三部分 跨分类互斥（丙批）

现在有跳过规则三十四条、互斥二十三条、单值七条、遮挡两条。以下六类仍无约束。

## 一、地域 × 肤色

地域格：黑人、白人、混血、中东、欧美、东亚等。
肤色格：雪白皮肤、瓷白、冷白皮、棕褐皮肤、小麦肤色、日晒肤色。

两边独立抽，会出「黑人，雪白皮肤」。这类矛盾在下游剧情组合里已经出现过实例。

**建议**：地域与肤色共享一张对照表，抽到地域后肤色只在该地域的候选里挑。

## 二、身材 × 胸围

身材格：丰满、肉感、娇小丰满、丰腴。
胸围格：贫乳、微乳。

会撞成「丰满，贫乳」。

**建议**：胸部大小与身材类型共用一个连续刻度，不允许两端同时出现。

## 三、年代

服装格里有汉服、宫装、道袍、民国学生装、仙侠劲装；场地格里有客栈、洞府、马车、药浴桶、神社后山；同时又有一整套现代场地：便利店、地铁、飞机头等舱、胶囊旅馆。

两边都没有年代标记，于是「马车里穿 JK」「太空站里穿道袍」。

**建议**：服装与场地各标一个年代（古、近代、现代、未来），只同时代互配。

## 四、同义三重

「半脱」这个意思可以由三处分别表达：

- 穿脱格：衣襟大敞双乳外露、衣裳扯开挂在臂弯、只剩一点衣料、衣装半褪
- 衣物细节格：上衣掀到胸口、衣服挂在臂弯、半脱挂在手臂、褪到肩下
- 上衣款式自带的：只披一件外套里面真空、滑落一边的浴袍、湿透白衬衫

三处各抽一条，一句话里三个同义分句。

**建议**：增强模式加一道同义去重，同一语义只保留先抽到的一条。

## 五、光线写了两遍

镜头格有「逆光」，光影色调格有「逆光轮廓」，光位格有「右上逆光」。三处都能表达逆光。

**建议**：光线只在光影色调格里出，其它格禁止出现光线词。

## 六、描写长度极不均衡

光质格里有四条二十字以上的长句：水面折射下的丁达尔光束与细小气泡、摇曳烛光与深邃阴影的强烈明暗对比、体积雾营造出的空灵胶片感、熔岩与烈焰带来的橙红轮廓光、暗色调环境光与微弱轮廓光交织。

同格其余都是两到四字。抽到长句，整段读起来像换了个人写的。

**建议**：同一句里超过十五字的描写最多一条，或将长句改短。

# 第四部分 增强模式的可解释性

增强模式所有校验都开着，好处是矛盾少，代价是容易把格子查空。用户看到一个空格时，分不清是「本来就没有」还是「被拦了」。

建议两点：

1. 格子被清空时，直接显示一句原因，例如「本场景下无可用词，因为已选全裸」。
2. 灰掉的词可以点开看理由，显示被哪一条规则挡住。

这两件事的数据其实都已经算出来了，只是没呈现到界面上。调词库的人不用读代码就能知道该改哪条规则。

# 第五部分 验收方法

每批做完，用同一套抽法验证，不靠肉眼印象。

## 甲批（词条归位）

连抽五十次，检查是否还出现以下句式：

- 颜色格里出现「双腿分开」这类姿态词
- 「没穿胸罩的半罩杯」
- 「一只手抓着头发的齐肩短发」
- 动作段出现「缓慢前后移动」与性行为同框

四项都不再出现，算通过。

## 乙批（顺序调整）

连抽二十次，检查：

- 开场日常是否都在性行为之前
- 穿脱状态是否在衣物列举末尾
- 环境痕迹是否紧跟场景、不再出现在最后一段
- 内衣是否在外衣之前

## 丙批（跨分类互斥）

针对每一条各抽五十次，统计违例次数：

- 地域与肤色矛盾
- 身材与胸围矛盾
- 服装与场地年代矛盾
- 同一句出现两个「半脱」
- 同一句出现两处光线描写

全部为零才算通过。允许偶发就必须写明允许比例。

# 附录 未覆盖与待复核

以下三项本轮没有查，需要另做：

1. 上衣款式格（约三百条，导出时被截断）与场地、身份、职业的对应关系，只抽查了开头部分。
2. 性行为格（一百五十余条以上，导出时被截断）与姿势白名单的覆盖率，需要跑一轮全量配对。
3. 男性三格（穿着、特征、体型）与女性服装的呼应关系，例如她穿婚纱而他穿背心短裤，本轮未展开。

这三项建议在丙批做完后单独做一次，因为它们影响的是「搭配是否合理」，与本文的矛盾检测不是一类问题。
